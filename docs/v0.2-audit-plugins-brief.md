## 1. 一句话目标

在 **不改 audit 文件协议** 的前提下，把「记一条 open 批注」从  
**复制粘贴 / 下 md / 手填模板**  
升级为  
**在阅读现场选中 → 点一下 → 直接写入知识库 `audit/`**。

改正文与归档仍由 Agent「处理批注」负责（v0.2 **不**做自动 accept）。

### 3.3 依赖与约束

- **协议兼容**：生成文件必须能被现有 `audit-file.py` / `audit-review.py` / lint / SKILL 工作流 12 读懂。
- **路径**：`target` 相对知识库根（如 `wiki/entities/Foo.md`）。
- **默认只写 open**：`status: open`，目录 `audit/`（非 `resolved/`）。
- **Windows + Codex 主用户** 仍优先；插件本身跑在 Obsidian（跨 OS），文档给 Windows 路径示例。
- **本地优先**：不强制云同步；不上传正文到第三方。

## 5. 功能规格（Obsidian MVP = V2）

### 5.1 必须有

| 功能 | 验收要点 |
|------|----------|
| 命令 / 右键「记 llm-wiki 批注」 | 无选区时提示；有选区才打开 |
| 自动 `anchor_text` = 选区原文 | 与页面一字不差 |
| 自动 `target` | 当前文件相对 vault 根；须在 `wiki/` 或约定路径下，否则警告 |
| 自动 `target_lines`（尽力） | 1-based 估算；可不准，靠 anchor 定位 |
| 可选 `anchor_before` / `anchor_after` | 各截断 ~80–200 字 |
| 弹层：severity + comment + author | severity 四档与协议一致 |
| 写入 `audit/YYYYMMDD-HHMMSS-slug.md` | frontmatter 完整；`source: obsidian-plugin` |
| 成功提示 | 显示相对路径；可「在文件树中显示」 |
| 不改正文 | 插件不修改 target 文件内容 |

### 5.2 应该有（MVP 可后移但仍属 v0.2）

| 功能 | 说明 |
|------|------|
| open 列表视图 | 当前 vault 下 `audit/*.md` 条数与 target 分组 |
| 「复制处理提示」 | 生成给 Codex 的短句：处理批注 + 可选 id |
| 设置项 | 默认 author；是否要求必须在 wiki 页 |

### 5.3 可以有（v0.2 尾巴或 v0.2.1）

| 功能 | 说明 |
|------|------|
| 图谱 HTML 选区批注 | 见 §7 |
| 共享 `audit-shared` TS 包 | 插件与 HTML 共用序列化/校验 |
| 从 open 跳转 target 高亮 | 依赖 Obsidian API |

## 6. 数据契约（冻结）

与 [audit-guide](../references/audit-guide.md) 一致，插件 **不得** 发明字段：

```yaml
id: YYYYMMDD-HHMMSS-<4hex>
target: wiki/.../*.md          # 相对库根，正斜杠
target_lines: [start, end]    # 1-based
anchor_before: "..."
anchor_text: "..."            # 必填，verbatim
anchor_after: "..."
severity: info|suggest|warn|error
author: string
source: obsidian-plugin       # Web 侧用 web-viewer
created: ISO-8601
status: open
```

正文结构：

```markdown
# Comment
...
# Resolution
<!-- 处理时填写 -->
```

**兼容测试**：同一 vault 内，插件写入的文件与 `python scripts/audit-file.py ... --source obsidian-plugin` 在字段集合上等价（允许 id/时间戳不同）。

## 7. Web / 图谱路径（V5，可选增强）

| 方案 | 利 | 弊 |
|------|----|-----|
| A. HTML 内嵌表单 → 仍下载 md | 实现快；file:// 友好 | 仍要人手放 `audit/` |
| B. 本地 helper（小 HTTP / 命名管道） | 真写盘 | 多一个进程；安全边界 |
| C. 自定义协议 `llm-wiki://audit?...` | 可唤起助手 | 需装 handler |

**v0.2 建议**：先 **V2 Obsidian** 闭环；V5 默认采用 **A 增强**（从 graph 预填 target + 选区），真写盘 B/C 仅当用户强需求再开。
